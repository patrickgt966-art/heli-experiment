Without this website

Every check above can be repeated with the official Solana command-line tools. Replace the addresses with the ones shown on this page and in the GitHub repository.

Program, data length and upgrade key
solana program show <PROGRAM_ID>
Hash of the code on chain
solana-verify get-program-hash <PROGRAM_ID>
Rebuild from source and compare
solana-verify build in heli-v20-package/heli/solana-v20, then solana-verify get-executable-hash on the result
Mint authority, freeze authority and supply
spl-token display <MINT>
