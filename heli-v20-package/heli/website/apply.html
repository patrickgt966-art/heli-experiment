OFFICIAL HELI APPLICATION ENTRY

Start with your wallet.

This is the identity pilot for HELI's initial free allocation. It does not distribute tokens yet.

Wallet → identity → application result

  1. 01

    Connect your wallet

    Connect Phantom and sign a wallet ownership message. No SOL payment is requested.

  2. 02

    Complete identity verification

    Use Didit's document and face checks. On a phone, move to Safari or Chrome using your private application link if the wallet browser cannot use your camera.

  3. 03

    See your result

    Return to the application and press Refresh status. Approved, declined, pending and review results are displayed clearly.

Temporary test service · No token delivery

The pilot currently runs on a project computer. It can be offline when that computer or its temporary connection stops. Permanent application hosting is still pending.
